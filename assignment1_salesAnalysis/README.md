# Assignment 1 – Coffee Shop Sales Analysis

Analysis of the [Coffee Shop Sales](https://www.kaggle.com/code/ahmedabbas757/coffee-shop-sales/notebook) dataset: 149,116 transactions from three NYC coffee shops, January–June 2023.

## Files

| File | What it is |
|---|---|
| `sales_analysis_report.txt` | Written report: understanding of the data, 3 data-backed recommendations, questions |
| `sales_analysis.py` | Stores the sales variables, calculates drink/pastry revenue, prints the report, checks the $500 goal with if/else, and produces the data for each recommendation |
| `data/coffee_shop_sales.csv` | The dataset |
| `output/` | CSV tables produced by the script for each recommendation |

## Run it

```bash
pip install pandas
python sales_analysis.py
```
